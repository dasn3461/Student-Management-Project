# Student Management System

A Django-based web application for managing students, teachers, classes, attendance, grades, and enrollments. This project is designed to make it easy for educational institutions to manage their day-to-day operations efficiently.

## Features

- **Student Management**: Add, update, and view details of students.
- **Teacher Management**: Add, update, and view details of teachers.
- **Class Management**: Manage classes and their assigned teachers.
- **Attendance Tracking**: Record and view attendance of students.
- **Grade Management**: Assign and view grades for students.
- **Enrollment Management**: Handle student enrollments in different classes.

## Technologies Used

- **Backend**: Django 5.x
- **Frontend**: Bootstrap 5
- **Database**: SQLite (default, replaceable with other databases)
- **Authentication**: Django's built-in user authentication
- **Icons**: Font Awesome
